## Instructions

[hr][/hr]
1. Select a colonist
2. Right-click a party spot
3. ???
4. Party your f****** ass off!

The forced party can ignore certain conditions that would normally prevent a party from starting, such as bad temperature, danger, etc. So beware and/or enjoy!
